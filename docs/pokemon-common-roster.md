# 常见伙伴名单：主角团与火箭队历代阵容

普通球常见池：去重后 167 个形态。名单保留历史进化阶段、寄养、放生及曾交易获得的伙伴。传说、幻之和超级进化不进入普通球。

其中美录坦、美录梅塔虽然是小智的伙伴，但属于幻之宝可梦，仅大师球可抽。鬃岩狼人采用小智拥有的黄昏形态；大葱鸭采用伽勒尔形态；武藏的南瓜精与南瓜怪人采用特大尺寸。

不计入：只结伴未收服的鬼斯通、临时照顾的幼基拉斯、洛托姆图鉴、误送或借用的喷火龙／波士可多拉、火箭队自动贩卖机提供的临时宝可梦。火箭队喵喵是同行伙伴，按用户指定阵容纳入。
