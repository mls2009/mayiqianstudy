# 宝可梦学习探险（2026-11-03）

## 当前功能

- 图鉴接入 PokeAPI 当前全部 **1,025 物种、1,351 战斗条目**，附 1,579 条外观形态元数据。1,351 个条目均有独立本地 PNG 和对应游戏叫声 MP3。
- 官方 CSV 生成中文名、属性、身高体重、介绍、进化阶段、传说／幻之标记及超级进化标记。375 个条目的源资料缺官方中文介绍，界面明确标为「基于源数据的中文资料摘要」，保留原文和语言字段。源资料缺体重或分类时如实提示。
- 分页每页36项，可按名字、英文名、编号、属性、家族、收藏状态和抽取类别筛选。已拥有卡片右下角显示数量，每次重复的时间、球种和学习任务均保留。
- 可交互放射关系图覆盖全部家族。实线连接实际进化（含源数据指定的地区形态），虚线为同物种形态关系；不能把地区形态关系视为能随时相互变身。点击任意节点可读资料、听叫声、看上下游和收藏。
- 首页不再显示动画入口。普通球与大师球预览藏在家长规则内，实际抽取时正常播放仪式。

## 学习与领取

两项必选是识字学习、英语阅读。两项可选默认「完成8篇英语作业」「识字10个」，开始前可编辑；开始后锁定当天约定，避免临时加量。

领取分为两组，两个账号完全相同：

| 学习组 | 必选 | 对应可选 |
|---|---|---|
| 识字组 | 识字学习 | 识字10个 |
| 英语组 | 英语阅读 | 完成8篇英语作业 |

**每组每天领取一次，互不影响。** 本组必选完成即可领1普通球，不要求另一组必选也完成。本组必选与对应可选都完成后，可选区只显示一个「领取奖励」入口，点击弹出图标选择框：普通球图标＋×2，或金色大师球图标。取消不领取，点选图标才入库；也可选择原来的必选1普通球。任一方案领取后，本组必选与可选各保留一个灰色「已领取」按钮，不再出现两个可选已领取框，不能补领或改选。另一组继续独立领取。

两个普通球是一次领取并原子入库，然后依次播放揭晓动画；关闭或跳过不丢伙伴。两组都选升级奖励时，每天最多4普通球或2大师球，也可混选。已准备但未领取的组资格跨日保留。

旧版无学习组信息的已领取记录保留并标为「旧版已领取」，不推断所属组或自动补发。旧版未领取的学习计划可直接使用分组规则。原始历史规则和概率快照不改写。

## 分类与概率

| 类别 | 普通球 | 金色大师球 |
|---|---:|---:|
| 常见伙伴 |20%|0|
| 基础宝可梦 |50%|0|
| 进化一次 |20%|55%|
| 进化两次 |10%|30%|
| 传说 |0|5%|
| 幻之 |0|5%|
| 超级进化 |0|5%|

常见名单按用户指定，为小智、小刚、小霞、武藏、小次郎历代收服／拥有的伙伴与火箭队喵喵，含历史进化阶段、寄养与放生。去重并排除传说／幻之／超级进化后167个形态。详见 [完整名单](pokemon-common-roster.md)，来源记录于 `pokemon-trainers.js`。

普通球优先把上述形态归入常见池；大师球按真实进化阶段重新分池，因此喷火龙等熟悉伙伴也可从大师球获得。超级进化、幻之、传说标记优先于熟悉伙伴，普通球严格排除三类。大师球普通档保证至少进化一次，传说／幻之／超级进化是明示的独立特殊档，不要求其存在普通进化链。

先抽类别，再按该池内权重选宝可梦。未拥有形态权重1，已拥有形态权重0.5，重复次数再多也不继续递减。每个孩子按自己的收藏计算；不会影响另一账号。类别总概率不受池内条目数与重复降权改变。服务端使用加密随机数，CAS版本比较防并发重复领取。

## 两套独立数据库

`account-databases.mjs` 固定账号与 D1 绑定：

- 马亦谦 → `DB_MAYIQIAN` → `pokemon-ma-yi-qian`
- 马熠初 → `DB_MAYICHU` → `pokemon-ma-yi-chu`

学习、收藏及原有行为打分均选取各自数据库；运行时不会回退旧共享数据库。未知账号或缺绑定会拒绝请求。两个数据库已在 Cloudflare 创建并初始化。

`python3 scripts/migrate-account-databases.py` 从旧库只读复制各账号行（INSERT OR IGNORE，不覆盖目标已有记录），再核对所有源记录ID都存在于各自目标库且没有其他账号记录。2026-11-03验证：马亦谦1120条，马熠初146条；原库未删除或修改。旧云库尚无 adventures 表，浏览器本机收藏继续按原账号键保留，未自动上传或覆盖。

切换账号会立即清空旧打分显示；迟到的旧账号请求不会覆盖新账号。宝可梦读取使用独立用户键与请求代数保护；本机备份禁止跨账号恢复。

## 资源与动画

- `pokemon-full-data.js`：生成的全量资料，浏览器及Worker共用。
- `assets/pokemon-data-audit.json`：数据源URL、行数、SHA256、资料覆盖情况。
- `assets/pokemon-assets-audit.json`：逐条图片获取情况、回退源、MP3时长与对应叫声ID。
- `assets/pokemon/{id}.png`：优先 PokeAPI official-artwork；缺失时用其 HOME、游戏精灵图等对应形态资源。四个故勒顿／密勒顿非战斗形态使用 API 指定的朱／紫 WebP 资源转PNG，不用其它形态冒充。
- `assets/pokemon-cries/{id}.mp3`：PokeAPI/cries 的对应ID游戏叫声，响度归一化并转MP3，兼容iPhone。角色与资源归各权利人所有。不是动画片喊名字的配音。
- 球体为原生WebGL空心半球，平滑光照，固定后铰链，上盖1.3秒掀开112度。大师球同样保持实体结构，金色材质、M标记、肩部装饰和金色释放光效。
- 约8.75秒完整演出，可跳过／关闭；默认开声音，在点击时解锁音频。iPhone不支持网页定时振动，仅保留摇动与声音。减少动态效果时直接揭晓。关闭会释放GPU资源、定时器和音效；重播不加收藏。

## 本地开发和验证

前端：`python3 -m http.server 8765 --bind 0.0.0.0`。

后端：先分别执行 `wrangler d1 execute pokemon-ma-yi-qian --local --file schema.sql` 与 `wrangler d1 execute pokemon-ma-yi-chu --local --file schema.sql`，再执行 `wrangler dev --ip 0.0.0.0 --port 8787`。localhost与局域网开发前端使用同主机8787端口，公开网站仍使用 `https://api.mayichu.top`。

`?preview=1#pokemon` 明确选用本机收藏，按账号分别保存，适合检查界面；不会自动同步云端。生产发布使用 `wrangler deploy` 更新API，Pages项目为 `mayiqianstudy`，正式域名为 `https://mayichu.top`。静态发布仅打包浏览器文件、图标与assets，不包含数据库、Worker源码或本地开发缓存。

重建资料：`python3 scripts/build-pokemon-data.py --source /tmp/pokemon-full-source`（缺CSV会从PokeAPI官方仓库下载）。下载叫声仓库后，执行 `python3 scripts/fetch-pokemon-assets.py --cries <cries/pokemon/latest目录>`，可断点续跑；需curl、Pillow、ffmpeg、ffprobe。图片完整解码，所有MP3用ffprobe核对时长。

当前50项测试通过。测试：`node --test tests/*.test.cjs tests/*.test.mjs`。范围包括全量数据、全部家族关系与布局、实际地区进化、默认任务、分组领取／必选可选互斥／禁止补领／两球原子入库、概率边界／禁止池、精确重复半权重、旧历史兼容、独立数据库／并发领取、打分账号切换迟到响应、音频关闭清理。

手机实机扬声器音量和流畅度仍需要用户在iPhone体验；桌面浏览器手机尺寸检查不是实机测试。
