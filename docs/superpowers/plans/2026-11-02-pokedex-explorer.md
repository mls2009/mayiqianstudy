- [x] 主页面明显提供「播放相遇动画」「打开关系图鉴」，预览不新增记录。
- [x] 关系探索使用网络加资料面板，点击节点同步更新；支持直接选择 59 种宝可梦和在前后形态之间继续浏览。
- [x] 浏览器验证入口、未收集伙伴、节点资料、跨家族选择、记录不变与手机布局。
