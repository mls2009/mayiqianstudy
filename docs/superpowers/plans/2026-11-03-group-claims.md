# 识字／英语两组独立领取修正

用户已确认：识字必选（任务0）对应识字10个可选（任务3）；英语必选（任务1）对应8篇英语作业可选（任务2）。两账号规则完全相同，每组每天领取一次。

每组有三个互斥方案：必选完成领1普通球；必选与对应可选完成可改领2普通球或1大师球。领取任何方案后，该组所有领取按钮保留、变灰并显示「已领取」，另一组不受影响。不允许先领必选再补领可选。2普通球一次领取、原子入库，按顺序播放；关闭动画不影响已得伙伴。概率、重复降权、两账号数据库、全部图鉴与关系图不变。

旧版无学习组信息的当日已领取记录保留，标记为旧版已领取，不推断学习组或自动补发；无领取的旧计划可直接使用新规则。
